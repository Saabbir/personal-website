# Claude Instructions - Saabbir Portfolio & Blog

This is an Astro 4+ portfolio and blog project using SCSS (BEM) and MDX Content Collections.

- Read `AGENTS.md` before making any code modifications.
- Commands:
  - Development server: `npm run dev`
  - Production build: `npm run build`
  - Preview build: `npm run preview`
  - Type check: `npx astro check`
- Architecture:
  - BEM class naming (`.c-block__element--modifier`).
  - Dark/Light Theme with zero FOUC script.
  - MDX blog post engine with "Edit on GitHub" link.
  - Working Contact Form, WhatsApp floating widget, and Giscus Comments.
