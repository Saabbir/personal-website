# Site hosting cookbooks

Beginner guides for putting a static personal site on the internet with **Git**, **GitHub Actions**, **GitHub Pages**, and **DNS**.

These pages are written for GitBook. They do not publish as posts on the live site.

## Who this is for

Someone who can edit files and click around GitHub, but has never bought a domain, never set an A record, and does not think of themselves as a DevOps engineer.

## How to import into GitBook

1. Create a GitBook space.
2. Connect this repository (or copy this `cookbooks/` folder into a docs repo).
3. Set the space root to `cookbooks/`.
4. Use [SUMMARY.md](SUMMARY.md) as the table of contents if your GitBook setup still reads one.
